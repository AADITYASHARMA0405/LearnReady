# LearnReady

[![standard-readme compliant](https://img.shields.io/badge/readme%20style-standard-brightgreen.svg?style=flat-square)](https://github.com/RichardLitt/standard-readme)

> A comprehensive React Native Expo application for interactive learning, skill tracking, and interview preparation.

LearnReady is designed to help users prepare for interviews, take diagnostic assessments, and track their proficiency across various subjects and skills.

## Background

The project aims to create a unified platform for learning and career readiness. It provides a structured environment where users can engage in interactive lessons, evaluate their knowledge through quizzes and diagnostic tests, and simulate mock interviews to build confidence.

## Install

This project uses React Native and Expo. To get started locally, you will need to have [Node.js](https://nodejs.org/) and [Expo CLI](https://docs.expo.dev/) installed.

```sh
# Clone the repository
git clone https://github.com/AADITYASHARMA0405/LearnReady.git

# Navigate to the project directory
cd LearnReady

# Install dependencies
npm install
```

## Usage

To start the development server, run:

```sh
npm start
```

This will start the Expo Metro bundler. You can then open the app on your physical device using the Expo Go app by scanning the QR code, or run it on an iOS Simulator/Android Emulator.

## Features

- **Interactive Lessons**: Step-by-step learning modules across various subjects.
- **Skill Tracking**: Visual progress indicators for skill proficiency.
- **Mock Interviews**: Simulated interview environments to practice and refine answers.
- **Assessments & Quizzes**: Diagnostic tests to evaluate current knowledge levels.
- **Multi-language Support**: Built-in internationalization (i18n) support (e.g., English, Kannada).
